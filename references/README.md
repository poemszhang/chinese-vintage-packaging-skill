# 参考图库说明

> **重要**：本 Skill **不是**机器学习「训练」，不使用 LoRA / fine-tune。  
> 参考图的作用是：Agent 在生成前 **读取这些图片**，提取视觉 DNA，写入提示词或作为 image-to-image 参考。

## 目录结构

```
references/
├── REFERENCE-CATALOG.md      ← 完整图库索引（必读）
├── curated/
│   ├── eaga/                 ← East Asian Graphics Archive 高清图
│   ├── thepaper-10027316/    ← 澎湃新闻「百年上海设计」展图（20 张）
│   └── douyin-video-frames/  ← 抖音视频帧（6 张）
├── douyin-video-frames/      ← 原始抖音帧（同上，主副本）
└── _excluded/                ← 含政治敏感内容，Skill 不使用
```

## 生成前必须做的

1. 读 [REFERENCE-CATALOG.md](REFERENCE-CATALOG.md)，按品类选 1–3 张最接近的参考图
2. **Read 工具打开参考图**，确认色彩、字体、边框、印刷质感
3. 将观察到的特征写入提示词（不要只说「参考这个风格」）
4. 若用户给了参考图，与用户图 + 本库图合并理解
